# A importância da água e os impactos ambientais no agronegócio

Projeto desenvolvido para o projeto agrinho.

# Agro Forte: Futuro Sustentável
# 🌱 Breve explicação do site

💧 O site apresenta a importância da água no agronegócio e os impactos ambientais relacionados ao uso dos recursos naturais. 🌎 Seu objetivo é conscientizar sobre a sustentabilidade e a preservação do meio ambiente no campo.

# 🎯 Objetivo do site

🌿 Informar e incentivar práticas sustentáveis no agronegócio, mostrando como o uso consciente da água contribui para um futuro mais verde e equilibrado. 💙

# 🛠️ Recursos técnicos utilizados

✨ Layout responsivo para celular e computador.
✨ Cards informativos com efeito ao passar o mouse.
✨ Organização do conteúdo em seções.
✨ Design moderno com cores inspiradas na natureza. 🌳

# 💻 Tecnologias utilizadas

🌸 HTML5 — estrutura e organização do conteúdo.
🎨 CSS3 — estilização, responsividade e efeitos visuais.
🚜🌱 Desenvolvimento voltado para educação e conscientização ambiental. 💧🌎✨
